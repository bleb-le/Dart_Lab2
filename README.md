# **Ответы на вопросы**

* *В чём разница между полем класса и обычной переменной в функции?*
Поле класса принадлежит объекту и существует, пока жив объект. К нему можно обращаться из любого метода этого класса. Обычная переменная внутри функции - локальная, она создаётся при вызове функции и исчезает после её завершения, доступна только внутри этой функции!

* *Что такое конструктор и зачем он нужен?*
Конструктор - это специальный метод, который автоматически вызывается при создании объекта. Он нужен для того, чтобы задать начальные значения полей объекта. Без него поля остались бы пустыми или неинициализированными.

* *Зачем нужен @override перед toString()? Что будет если его убрать?*
*@override* - это аннотация, которая говорит компилятору: «этот метод переопределяет метод родительского класса». Она защищает от опечаток в имени метода. Если её убрать, код продолжит работать, но компилятор не подскажет, если случайно написать *toStrng()* вместо *toString()*!!

* *Чем статическое поле static int counter отличается от обычного поля? Сколько копий этого поля существует в программе?*
Обычное поле принадлежит каждому объекту отдельно. Статическое поле принадлежит классу целиком и существует в единственном экземпляре на всю программу. Все объекты класса видят одно и то же значение этого поля. В программе существует одна копия статического поля.

* *Что означает нижнее подчёркивание в _counter?*
В Dart нижнее подчёркивание делает идентификатор приватным для файла, в котором он объявлен, обратиться к нему можно только внутри файла lib/todo.dart! Из других файлов напрямую достучаться до _counter нельзя!!
